Authentication and operator-security behavior is documented in ADR-003. Custody case lifecycle, access, membership, and concurrency are documented in ADR-004. Digital-evidence registration, integrity, persistence, and filesystem storage are documented in ADR-005. The custody-event model, canonical hashing protocol, append-only persistence, registration genesis, backfill, read APIs, and chain verification are documented in ADR-006. Evidence transfer, descriptive metadata update, file-integrity verification, sealing, and release — with their authorization matrix, lifecycle graph, locking and transaction contract, and Problem Details catalogue — are documented in ADR-007.
